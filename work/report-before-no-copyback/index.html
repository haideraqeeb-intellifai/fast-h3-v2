Exact schedule and configuration

The published eight-forward ladder is [999, 874, 749, 624, 500, 375, 250, 125]. This experiment takes every other rung: [999, 749, 500, 250], followed by terminal zero. Five sigma-grid points produce exactly four transformer forwards. Video/audio shifts remain 10/3.

The official eight-step entrypoint rejects this override. A separate local model view links the unchanged original weights and carries an explicitly marked experimental schedule. The original model contract remains intact. This is neither an official four-step recipe nor a separately distilled four-step checkpoint.

Does V2 support Ref2VA?

No supported distilled Ref2VA mode is provided by this checkpoint. The official model card states that it supports text-to-audio-video and that FL2VA and Ref2VA were not distilled. FastVideo has Ref2VA code, but this checkpoint's modular index points its transformer_ref component to MiniMaxAI/MiniMax-H3. Using that component would use the base model's reference transformer, not V2's distilled text-to-audio-video transformer. No Ref2VA generation was attempted.
